## Decisions needed

- **Grey hatch flagged by Impeccable** as a "repeating-stripes" generated-UI signature (advisory). It is the accepted missing-data treatment, so it stays; recorded here, not applied.
- **Typeface.** Atkinson's slashed zero is prominent in large figures ("30%", "0%"). It is legible by design but reads technical in a headline figure. Decide Atkinson versus system font, or Atkinson for UI with the system font for display figures.
- **Re-stepping risk-fill lightness (finding 3)** changes the reference hexes while keeping the accepted roles. Confirm.

## What works (keep)

- Ledger structure, no cards, no numbered or all-caps chrome; Impeccable found 0 anti-patterns.
- Tags built from the exact legend swatch.
- The plain-language "Cómo escribimos" table.
- Selected-territory outline that keeps the fill; hatch for missing data; no horizontal overflow at 320–1024 px; token contrast pairs pass.

## Top 3 changes

1. Rebuild the opening as a national data story: headline insight, measure-titled legend, full-bleed mobile map (findings 1, 2).
2. Re-step the risk fills into an ordered light → dark scale within the accepted hues (finding 3).
3. Add the ranked compare-and-verify list with exact values, coverage and source line (findings 5, 6).
