Cómo mostramos una señal de riesgo sin acusar a nadie

Colores, cifras y componentes para que cualquier persona entienda en qué se usa el dinero público y decida qué revisar.

Dirección visual elegida. Componentes propuestos para revisión.

Lo que sostiene cada pantalla

Quien nos visita puede no saber leer una tabla ni un contrato. Estas reglas protegen lo que más importa: entender sin que nos acusen de acusar.

El mapa lleva el color

Una pregunta por vista. La interfaz es blanca y sobria para que el color de los territorios sea lo primero que se lea.

Una señal pide revisar, no condena

Siempre decimos qué se analizó, con qué cobertura y de dónde viene el dato. Riesgo bajo no significa que no haya irregularidades.

El color nunca va solo

Cada estado suma texto, forma o trama. La selección conserva el color del dato y se marca con un contorno aparte.

Lo desconocido no se pinta de cero

Sin análisis es un estado propio: trama gris y la etiqueta «Sin datos». Nunca se muestra como 0% ni como riesgo bajo.

Mismas palabras en todas partes

Nombres, unidades y componentes no cambian entre vistas. En el móvil reorganizamos el contenido y mantenemos controles fáciles de tocar.

Cómo escribimos

Lenguaje de todos los días, sin jerga de contratación. Decimos qué pasó y qué se puede hacer.

Un color, una función

Datos, acciones y mensajes tienen funciones distintas, aunque compartan una familia de color.

Riesgo en el mapa

Azul para menor riesgo, amarillo para el nivel intermedio y naranja/rojo para el mayor. Los valores son la referencia actual; los parámetros siguen pendientes.

__RISK_SWATCHES__

Sin umbrales inventados. Esta guía no asigna porcentajes a bajo, intermedio o alto. El gris con trama es falta de datos y nunca se sustituye por azul.

La base de la interfaz

Blanco para leer, azul oscuro para actuar, neutros para ordenar. Los tonos claros del mapa son rellenos, no colores para texto pequeño.

__UI_SWATCHES__

Mensajes de la interfaz

El verde confirma que una acción terminó; no declara «seguro» a un territorio. El rojo de un mensaje indica un problema recuperable, no una condena en el mapa.

__ICONS__

El ícono acompaña la etiqueta. Si va solo, necesita nombre accesible y un área de 44 × 44 px. No representamos «riesgo alto» con una calavera ni con un juicio de culpabilidad.

Alcance y referencias

Esta guía ayuda a diseñar interfaces; no es una biblioteca de componentes de producción ni una auditoría completa. Quedan pendientes la metodología, los umbrales, la unidad de agregación y las pruebas con datos reales. Geografía: geoBoundaries / OpenStreetMap, ODbL 1.0, simplificada.
