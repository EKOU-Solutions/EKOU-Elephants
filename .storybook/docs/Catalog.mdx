# Catálogo de componentes

Arma las pantallas solo con estas piezas. Cada componente tiene su página con propósito, controles, estados y accesibilidad.

- **Núcleo**: aceptado con la Ronda 05 (guía v1.0).
- **Candidato**: salió de las pantallas de ejemplo; se puede usar, pero la primera página que lo necesite lo confirma o lo descarta.

<CatalogTable />

Hoy estas historias son la **especificación v1.0** (marcado y clases `el-*`), todavía no componentes React de la app. Cuando un componente se implementa con el flujo `elephants-design`, su historia pasa a vivir junto al componente en `src/` (ver [Cómo trabajamos](?path=/docs/cómo-trabajamos--docs)).
