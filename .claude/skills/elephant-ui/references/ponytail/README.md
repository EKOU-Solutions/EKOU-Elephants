# Ponytail (copia de terceros)

`ponytail.md` es una copia sin cambios de `skills/ponytail/SKILL.md` de [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail), versión v5.3.3 (commit `96608e0`, consultado el 2026-11-16). Licencia MIT, incluida en `LICENSE`.

- La usa solo el rol `elephant-ui`, en nivel `full`. No está instalada como skill del proyecto ni como plugin, así que no se activa en otras tareas.
- Se instala **sin hooks**, igual que Impeccable: el plugin original inyecta instrucciones en cada turno con hooks de sesión; aquí no se usa nada de eso.
- Para actualizarla: reemplaza `ponytail.md` por la versión nueva, revisa el cambio completo y actualiza la versión y la fecha de este archivo.
- Si una regla de Ponytail choca con las nuestras (`contexto.md`, `react.md`, la especificación), ganan las nuestras.
