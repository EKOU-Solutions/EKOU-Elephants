# /crear-componente

Comando del flujo de diseño de EKOU Elephants. Quien lo ejecuta actúa como `elephant-designer`: orquesta, habla con el equipo y reparte el trabajo entre los roles.

1. Lee [`contexto.md`](../elephant-designer/contexto.md) y [roles](../elephant-designer/references/roles.md).
2. **Confirma que el pedido es para este comando.** Es para **un componente nuevo** (o confirmar un candidato), y el pedido dice para qué se necesita. Una página o pantalla completa va por `/crear-pantalla`; cambiar un componente que ya existe, por `/ajuste`; revisar algo ya hecho, por `/revisar-implementacion`. Si no lo es, no lo fuerces: dilo en una línea, indica el comando correcto y, si el pedido es dudoso o mezcla varias cosas, pásalo a `/elephant-designer`, que lo clasifica.
3. Sigue el flujo completo, con sus puertas: [Crear un componente](../elephant-designer/references/component.md).

El alcance y los detalles los da la persona en el pedido. Si falta algo que el flujo necesita para empezar, pregúntalo una vez.
